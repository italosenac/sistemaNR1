# E0 — Fundação técnica funcional

Origem: Missão 02 fornecida pelo usuário em 2026-09-26 e etapa E0 de [backlog](../../docs/backlog-mvp.md). Esta especificação técnica não modifica nem conclui os 21 RFs documentais.

## Escopo

Workspace pnpm com `apps/web`, `apps/api`, `packages/contratos` e `supabase/migrations`. Next.js App Router/React/Tailwind/shadcn com TypeScript strict. NestJS CommonJS/Jest, configuração validada, erros padronizados, CORS controlado, Swagger só em desenvolvimento. Contrato mínimo `RespostaDeSaude`. CLIs locais e versões fixadas.

## Comportamento

Página em português com título SistemaNR1, subtítulo Gestão de riscos ocupacionais e cartões M1/M2/M3 ainda não implementados. Consulta pública sem credencial ao `GET /health` da API configurada por `NEXT_PUBLIC_API_URL`, com estados carregando, conectada e indisponível; falha não derruba a página. Botão permite repetir consulta.

API retorna exatamente `{"status":"ok","servico":"sistemaNR1-api"}`. `GET /health` é exceção explícita ao prefixo `/api/v1`, usada para futuras verificações de hospedagem. Demais controllers futuros terão o prefixo. Nenhum acesso a Supabase é necessário para iniciar a página ou o endpoint.

## Critérios de aceitação

- **CA-E0-01:** Node LTS, npm, Git e pnpm executam; ferramentas locais têm versões compatíveis e registradas.
- **CA-E0-02:** Instalação pelo lockfile funciona; compilação topológica produz contratos antes das aplicações; TypeScript strict e ESLint passam.
- **CA-E0-03:** GET /health responde 200 com o contrato exato sem credenciais Supabase.
- **CA-E0-04:** Prefixo global vale para rotas comuns; erros retornam envelope estável sem stack, segredos ou mensagens internas de exceções inesperadas.
- **CA-E0-05:** Validação global rejeita DTO inválido/campos desconhecidos; CORS fornece permissão apenas para a origem configurada.
- **CA-E0-06:** Swagger existe somente com NODE_ENV=development e permanece ausente em produção.
- **CA-E0-07:** Navegador renderiza título/subtítulo e os três módulos não implementados; consulta real mostra API conectada.
- **CA-E0-08:** Com consulta pendente, mostrar carregamento; falha HTTP/rede/contrato inesperado mostra API indisponível sem remover o restante da página; nova tentativa recupera.
- **CA-E0-09:** Página utilizável em desktop e celular, sem overflow horizontal e com controles acessíveis.
- **CA-E0-10:** `pnpm dev` inicia web:3000 e API:3001 simultaneamente; builds de contratos, backend e frontend passam; produção escuta 0.0.0.0.
- **CA-E0-11:** Segredos não estão nos exemplos/frontend; arquivos .env reais são ignorados; CLI Supabase funciona sem conexão remota ou migrações.
- **CA-E0-12:** PDFs, 21 SPECs, Skills e instruções originais permanecem íntegros; documentação de execução e estado E0 são atualizados preservando histórico.

Jest com aplicação Nest real e Supertest para saúde, prefixo, DTOs, erros, CORS e documentação. Controllers de prova existem somente no teste. Playwright para navegador real, comunicação com API real, estados de falha e viewport móvel. Build/typecheck/lint/format são verificações adicionais. Evidências em [relatório E0](../../docs/validacao/relatorio-e0.md).
