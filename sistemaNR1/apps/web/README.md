# SistemaNR1 — frontend

Next.js App Router, React, TypeScript strict, Tailwind e shadcn/ui. Página inicial demonstrativa com consulta pública ao NestJS, estados de conexão e módulos M1–M3 pendentes.

Execute na raiz do workspace: `pnpm.cmd dev` (web + API) ou `pnpm.cmd dev:web` (somente web). Frontend em http://localhost:3000. Configuração opcional em `.env.local`, baseada em `.env.example`; nenhuma credencial é necessária para E0.

Instalação, testes e produção: [README principal](../../README.md) e [guia de instalação](../../docs/ambiente/instalacao.md). Componentes gerados com CLI oficial shadcn; fontes do sistema, sem downloads externos no build.
