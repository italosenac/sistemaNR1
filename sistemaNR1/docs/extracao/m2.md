             metodologia toda vez.

          • O n mínimo de 7 e a regra de maior magnitude são o que impedem que o

Numa fiscalização

          • A pergunta que o auditor/gestor faz não é "qual o nível do risco?". É
           "como você chegou nesse nível, e qual critério existia antes de você

               resposta é um PDF assinado, versionado, com hash e data anterior ao
               resultado.

               decisão. É a razão pelo qual o produto não é só "mais uma ferramenta de
